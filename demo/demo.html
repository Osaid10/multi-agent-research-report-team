keeping the supervisor dumb on tools
Every worker is a claude -p subprocess wrapped as a LangChain chat model. The supervisor's process is launched with --tools "" — so a tool violation is not prompted against, it is structurally impossible. It is handed a status summary, never the notes or the draft.

the finding

The average is a rounding error — and it hides the story. The team wins where the topic genuinely decomposes and loses on easy factual ones, because the planner splits a one-answer question five ways regardless. 43.5 searches per report against the baseline's 8.9.

Route simple questions to one agent; reserve the team for questions that need decomposing.
